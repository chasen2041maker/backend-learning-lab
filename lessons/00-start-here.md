# 第 0 课：把“AI 帮我完成”变成“我能掌控”

## 本课目标

- 明白后端学习不是背框架 API；
- 建立每次练习的固定闭环；
- 知道什么时候可以使用 AI。

## 五级掌握标准

同一项知识可以处在不同级别：

1. **见过**：看到名词不陌生；
2. **能跟做**：参考教程或 AI 可以运行；
3. **能解释**：能说出输入、状态变化、输出和失败点；
4. **能独立处理**：可以设计、实现、测试和排错；
5. **能权衡**：知道替代方案、成本和适用边界。

本仓库大部分内容要求达到第 3～4 级。不要因为代码运行了就在进度表打勾。

## 每个练习的固定流程

1. 先写一句需求和一张数据流；
2. 不看答案尝试 20～30 分钟；
3. 运行并保存完整报错；
4. 需要时让 AI 只给一个提示；
5. 修复后运行测试；
6. 故意制造一个失败；
7. 第二天关闭 AI，从空白重写关键部分；
8. 在 `progress/debug-log.md` 记录证据。

## 第一天任务

分别执行：

```powershell
git status
python --version
go version
```

然后回答：

- Git 仓库和正在运行的程序有什么区别？
- Python/Go 源文件为什么不会自动成为网络服务？
- 一个服务监听 `8000` 端口是什么意思？
- 进程退出后，内存中的工单为什么会消失？

回答不完整没有关系，把不知道的内容写进进度表。
